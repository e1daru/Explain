# Show why each step is valid

Use for a proof, equation, algorithmic invariant, or mathematical procedure
where a reader can follow the symbols but cannot justify the next step.

State the target, define needed symbols, and identify the rule used at the
first non-obvious transition. Use aligned equations, a step/reason table,
or a geometric construction when that representation exposes the reasoning.
Do not turn every arithmetic operation into its own paragraph.

Example request: "Why can I subtract the same number from both sides?"

| Step | Why it preserves the equality |
|---|---|
| x + 3 = 8 | The two sides have the same value. |
| (x + 3) - 3 = 8 - 3 | Removing equal amounts from equal values leaves equal values. |
| x = 5 | Simplify each side. |

The operation preserves which values of x satisfy the equation. Substitution
checks this example: 5 + 3 = 8.

A worked example can explain an idea without proving every general claim.
Distinguish those purposes. Keep domain restrictions beside the operation
they justify, such as a nonzero divisor. Avoid visual decoration that adds
no reason for a step, and do not present a few examples as a general proof.
